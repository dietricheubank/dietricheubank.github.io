# Decision Rights and RACI

R = Responsible (does the work), A = Accountable (final outcome), C = Consulted, I = Informed. Prefer exactly one A per decision.

| Activity | Executive sponsor | Service owner | Architect | Security | Project lead |
|---|---|---|---|---|---|
| Approve business case | A | C | C | C | R |
| Select solution design | I | A | R | C | C |
| Review security controls | I | A | C | R | I |
| Accept operational handoff | I | A | R | C | R |
| Track benefit realization | A | R | I | I | C |
