# Project Priority Studio 2.0

**Interactive weighted scoring + illustrative portfolio capacity planning.**

Open [version 2.0](./v2.html). Version 1.0 remains available via [index.html](./index.html).

## Features
- Five customizable criteria and weights (valid only if total = 100%)
- Editable score inputs, IDs and dependencies
- Configurable effort-point capacity
- An illustrative benefit-vs-effort scatter plot
- Greedy heuristic for a dependency-aware capacity shortlist
- Print-ready executive decision brief and CSV export
- Fictional example projects, no external services or data transfer

## Scoring
Weighted priority is the sum of criterion ratings (1–5) times their weights divided by 100. Default criterion names, weights and bands are **illustrative** and should be validated before real use.

## Capacity algorithm (not optimization)
The demo repeatedly selects the *currently eligible* initiative with the highest score-per-effort ratio, where eligible means all named dependencies are already selected and effort fits remaining capacity. This greedy approach is transparent but may miss better combinations, particularly with chained dependencies. **It is not a financial model, validated portfolio optimizer or automatic funding decision.**

## Data handling
Everything stays in the browser session. Values reset on page refresh; CSV export is manual. Do not put confidential records into a publicly shared browser session.

## Known limitations
No CSV import, risk-adjusted benefit forecasts, budget calendar, multi-period resource scheduling, persistence or authorization. The print brief is a lightweight report, not an approved business case.
